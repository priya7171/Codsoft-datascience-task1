# Titanic Survival Prediction Using Machine Learning

## Project Overview

This project focuses on predicting whether a passenger survived the Titanic disaster using Machine Learning.

As part of my Data Science internship task at CodSoft, I worked with the Titanic dataset and implemented a Logistic Regression model to perform survival prediction.

This project helped me gain practical experience in data preprocessing, data cleaning, exploratory data analysis, data visualization, and machine learning.

## Objectives

- Understand and explore the Titanic dataset.
- Perform data cleaning and preprocessing.
- Explore data using visualization techniques.
- Implement a Logistic Regression model.
- Evaluate model performance on training and testing datasets.

## Technologies and Libraries Used

- **Programming Language:** Python
- **Data Manipulation:** Pandas
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Algorithm:** Logistic Regression

## Project Workflow

1. **Data Collection:** Worked with the Titanic dataset.
2. **Data Preprocessing:** Prepared the dataset for model training.
3. **Data Cleaning:** Worked on cleaning the data.
4. **Data Visualization:** Used Matplotlib and Seaborn to explore the dataset.
5. **Model Building:** Implemented Logistic Regression using Scikit-learn.
6. **Model Evaluation:** Evaluated the model using training and testing accuracy.

## Model Performance

The results reported in this project are:

| Dataset | Accuracy |
|---|---:|
| Training Dataset | 79% |
| Testing Dataset | 81% |

These are the accuracy results recorded in my project.

## How to Run the Project

1. Clone or download this repository.
2. Extract the dataset archive if required.
3. Open `titanic-survival-prediction.ipynb` using Jupyter Notebook or Google Colab.
4. Install the required libraries if they are not already installed:

```bash
pip install pandas matplotlib seaborn scikit-learn
```

5. Make sure the dataset path in the notebook is correct.
6. Run the notebook cells to explore the data, train the model, and view the results.

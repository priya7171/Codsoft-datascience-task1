# Codsoft-datascience-task1
Task 1 have titanic dataset in which we have to predict the survived or not survived people.
I have learned the library like seaborn, sklearn, pandas and matplotlib during this task. I have used the modules like data preprocessing, data cleaning and visualizations technique. I have used here logistic regression a very common algorithm. I got an accuracy of 79 on training dataset and 81 on testing dataset.
